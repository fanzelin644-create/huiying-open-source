# 绘映产品需求文档（PRD）

版本：1.0｜日期：2026-09-13｜依据：本次完整创作流程、用户连续反馈、当前代码及竞品公开资料。

本文用于产品评审与后续研发拆解。标为“已验证”的内容有本次实测依据；“已实现”表示代码已有能力，不代表所有边界均通过实测；“待完善”为当前缺口；用户群体和商业模式中的“假设”需要后续研究。本文不将单个用户的反馈伪装为大样本市场结论。

## 1. 产品定位与问题

绘映帮助中文内容创作者从故事创意出发，依次完成剧本、角色/场景素材、分镜、场景概念图、视频及合成。核心价值是把创作决策、素材版本和生成范围保留在同一项目内，让用户可以先完成一个片段，再决定是否扩展。

本次用户能够完成一个片段的制作，但过程中反复遇到四类问题：不知道下一步；无法方便地缩小生成范围；无法判断任务是在等待还是失败；修改操作与模型调用的费用边界不清楚。产品下一阶段应优先解决这些问题，再扩展生成入口。

### 1.1 当前验证边界

- 一个本地项目完成六阶段流程，最终输出约 13.12 秒、1280×720、含音轨的 MP4。
- 最终仅保留一集、一个片段；这不证明多集批量生成、长片一致性或高并发已达到生产要求。
- 本次主流程成功视频使用 Seedance 2.0 标准版；之后视频及首帧模式默认模型改为 Seedance 2.0 mini。不能把标准版成功结果当作 mini 全流程验收。
- 当前产品为本地工作台形态，不能直接当作具备账户隔离、计费和协作能力的线上 SaaS。

## 2. 用户分析

| 用户层级 | 任务与动机 | 当前证据 | 产品重点 |
|---|---|---|---|
| 首要：独立视频/故事创作者 | 将想法做成可预览片段，快速判断风格与效果 | 本次用户明确要求先测试一个片段、使用便宜模型 | 小范围生成、明确费用边界、可修改、可恢复 |
| 次要：小型内容团队 | 复用人物与场景，逐集制作并审阅 | 目标用户假设，尚未访谈团队 | 资产复用、版本、审阅记录；协作为后续阶段 |
| 次要：素材型创作者 | 在画布上连接素材，探索多图参考视频 | 用户主动对标小云雀画布 | 上传、连接、引用、局部生成 |

核心任务表达：当我有一个故事想法时，希望先把其中一个片段做出来，能按意图调整，并清楚知道下一次点击会生成什么、是否花费模型费用。

用户表现出的偏好：不愿操作技术配置；希望 AI 分担修改；希望操作就在内容附近；愿意先试低成本结果。年龄、职业、收入、付费意愿等尚无证据，不建立虚构画像。

## 3. 用户调研与可用性发现

### 3.1 方法和样本

本轮为一位真实用户的连续任务式试用，材料包括聊天反馈、截图、对小云雀的实际交互观察，以及本地状态与输出核查。属于探索性可用性研究，没有标准化访谈录音、对照组或统计代表性。以下频次不解释为总体用户比例。

| 编号 | 观察/用户原意 | 解释与产品响应 | 状态 |
|---|---|---|---|
| U01 | 第一阶段出现 SOCKS 依赖错误 | 环境问题不应直接阻断用户且只显示英文异常 | 已做代理客户端修复；错误呈现仍需统一 |
| U02 | 第七个图片任务开始失败，前面完成后才继续 | 需要区分排队、限流、连接等待与失败；单凭截图无法确定账号并发上限 | 局部状态已改；全局队列待建设 |
| U03 | 分镜一次生成太多，只想测试一段 | 文本结果可以完整保留，付费生成必须按选择范围执行 | 已实现范围过滤 |
| U04 | 集数长列表不便操作 | 集级折叠、集内全选与片段左侧勾选 | 已实现 |
| U05 | 需要删除整集及选中片段 | 提供本集删除、批量删除与编辑期恢复 | 已实现；非持久撤销 |
| U06 | 顶部批量工具栏重复 | 操作靠近集标题；全局冗余栏取消 | 已实现 |
| U07 | 勾选后还要保存才可生成 | 一次点击完成保存和启动；保存失败不能启动 | 已实现 |
| U08 | 保存慢 | 保存数据与模型生成解耦，避免等待心跳才结束 | 完成通知已修复 |
| U09 | 没主动重试却出现“重新生成” | 自动评估故障不能触发多次付费重画 | 已修复评估不可用分支；质量重试仍需预算规则 |
| U10 | 图片完成后不知道下一步 | 给出明确“确认场景概念图，生成视频”入口 | 已实现相关入口 |
| U11 | 要多图参考，不应强制首帧 | 引用模式与首帧模式分别呈现 | 画布已有多图参考；主流程需继续统一 |
| U12 | 双击画布菜单、视频底部操作框 | 保持创建、选择、配置的空间一致性 | 已实现相关交互 |
| U13 | “参考图”应叫场景概念图 | 统一用户可见术语 | 已改主流程文案 |
| U14 | 剧本只有保存，取消难找；希望 AI 帮改 | 固定底栏补齐取消；提供指定范围 AI 修改与对比采用 | 新增待实施需求；正文已有取消但底栏缺少 |

### 3.2 后续研究计划（尚未执行）

招募 6–8 位独立创作者及 3–4 位小团队成员，覆盖无模型经验与有生成经验者。让受试者独立完成：导入想法、选择单片段、AI 改写、替换素材、生成、导出及失败恢复。记录任务成功率、求助次数、误触发生成次数、下一步识别时间和对成本的理解。访谈现有工具、月制作量、返工来源与付费决策。小样本先发现问题，再决定是否做规模化问卷。

## 5. 功能链路与信息结构

主链路：创意输入 → 剧本审阅 → 角色/场景素材 → 分镜选择 → 场景概念图审阅 → 视频生成 → 按集合成与导出。

每个阶段的共同操作：查看结果 → 手动修改或 AI 辅助修改 → 预览/采用 → 确认进入后续阶段。AI 辅助修改中“预览/采用”是目标交互，尚未完整落地。

| 阶段 | 输入 | 输出 | 用户决策 | 成本边界 |
|---|---|---|---|---|
| 剧本 | 创意、风格、集数等 | 结构化故事、人物、场景、分集 | 采用、手改、续写；计划增加局部 AI 改写 | LLM 生成/改写会调用模型，普通保存不调用 |
| 角色 | 剧本中的人物与场景描述 | 可选择的素材版本 | 重试、上传、选择版本 | 图片生成收费与否以提供方结算为准 |
| 分镜 | 剧本与素材信息 | 集→片段→镜头 | 编辑、折叠、选择、删除 | 文本生成调用 LLM；勾选/保存不生成图片视频 |
| 场景概念图 | 所选片段、人物场景素材、视觉描述 | 概念图版本 | 人工检查并选定版本 | 仅所选片段生成；评估不可用不重画 |
| 视频 | 所选片段描述和选定图片 | 视频片段 | 预览、保留或重做 | 显示本次模型与参数；不默认重做成功结果 |
| 后期 | 所选有效视频 | 按集 MP4 | 下载和检查 | 当前为本地合成，不是专业时间线剪辑 |

画布为另一创作入口：空白处双击创建节点 → 上传/资产库添加素材 → 连线引用 → 选中视频配置 → 提交 → 查看结果。当前画布与主流程使用不同任务和数据结构，跨入口资产复用尚需统一设计。

## 7. 新增：手动编辑与 AI 辅助修改

### 7.1 编辑交互

进入编辑时创建本地草稿。固定底栏并排提供“取消修改”“保存”；取消只丢弃本次草稿，不影响已保存内容。保存中显示状态，成功后退出编辑，失败保留草稿与错误原因。切换阶段或关闭页面时对未保存内容提供保留/放弃选择，不能静默丢失。

### 7.2 AI 修改交互

1. 用户在剧本或分镜选择“AI 帮我改”，明确修改范围。
2. 输入自然语言要求，例如“保留人物设定，把这一集压缩到 30 秒”“只让选中镜头的对白更自然”。
3. 系统展示范围及约束，提交文本模型；期间允许取消等待，但不宣称一定取消提供方执行。
4. 以原文/候选对比展示变化，并说明时长、人物、场景或镜头数量变化。
5. 用户选择采用或放弃。采用时检验原稿版本是否仍一致，避免覆盖用户同时做的修改。
6. 若已有下游素材，显示受影响范围及“保留现有素材/稍后重新生成”的选择；重新生成必须由用户主动启动。

不接受 AI 越界修改未选片段；无效结构、丢失角色引用或不支持时长应提示修复，不能直接覆盖。精确时长压缩是目标约束，不能承诺模型一次必达。局部采用可作为后续增强，首版先支持候选整体采用与放弃。

## 8. 模型、费用与质量策略

当前文本使用 deepseek-chat，图片使用 doubao-seedream-5-0-260128，视频及首帧默认已设为 doubao-seedance-2-0-mini-260615。其他视频模式需要分别检查映射，不能假设都已切换。当前项目 720P 的配置并不会因为“便宜模型”自动降为 480P/5 秒。

建议提供明确测试预设：低成本模型、短时长、低分辨率，由能力注册校验支持后启用。生成前展示所选片段数、时长、模型与估算依据；定价和活动有效期必须从官方来源核实，无法估算时显示未知，不能填写虚构金额。保存、勾选、折叠不产生模型调用。

自动质量重试与服务故障重试分别管理。评估不可用转人工检查；质量不达标重试需有次数与预算上限。每次实际提交、提供方任务 ID、用量及结果均应可追溯。本文未验证完整账单，不提供本次实际人民币成本。

## 9. 指标与埋点设计

已知基线只有一个项目、一个片段成功导出；尚无产品级成功率、留存或 P95 数据。以下为待建设指标与建议验收目标。

| 指标 | 定义 | 目标/用途 |
|---|---|---|
| 越范围生成 | 未勾选片段触发的模型请求数 | 验收为 0 |
| 重复提交 | 同一用户操作产生非预期重复任务 | 验收为 0 |
| 首片段完成率 | 创建项目后成功导出至少一段的项目比例 | 先采基线再定目标 |
| 保存延迟 | 点击至服务端持久化确认 | 本地建议 P95 <1 秒，需专项测量 |
| 任务可追溯率 | 有实际模型和提供方 ID 的已提交生成任务比例 | 目标 100% |
| 修改采用率 | 被采用 AI 候选数/成功候选数 | 判断 AI 修改价值，不代替质量评分 |

计划事件：project_created、scope_changed、draft_saved、ai_revision_requested、revision_accepted/discarded、generation_submitted、generation_terminal、evaluation_unavailable、version_selected、final_exported。记录匿名项目标识、阶段、范围数量、模型和延迟，不采集 API Key；原文内容默认不进入分析事件。

## 10. 发布计划与测试门槛

第一阶段 P0：补齐编辑取消、错误保留、明确下一步、任务身份和生成范围。回归“只选一段”“零选”“保存失败”“刷新恢复”“评估不可用”“重复点击”。

第二阶段 P1：AI 修改候选与采用、下游影响提示、统一任务队列与测试预设。验收越界修改拒绝、原稿版本冲突不覆盖、放弃候选原文不变、采用不自动生成媒体。

第三阶段 P2：跨画布与主流程资产复用、多用户权限、协作和平台计费。依赖身份认证、存储隔离和计费审计，不能直接将当前本地服务开放公网。

范围过滤或幂等机制失败时应阻止新提交并保留项目，不能回退成全量生成。上线新数据结构前备份、可迁移读取旧项目，回退不删除已有输出。

## 11. 边界与开放问题

- 当前后期仅按集拼接，不包含专业剪辑时间线、混音、字幕精编的完整产品承诺。
- AI 生成标识、素材授权和版权来源需要产品单独管理；关闭可见水印参数不等于取得商业授权。

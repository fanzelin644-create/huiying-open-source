# 绘映无限画布

新增日期：2026-09-13。入口：侧边栏「无限画布」，或 http://localhost:3000/canvas 。原有创作工作流、沙盒和视频管线继续独立使用。

## 使用方式

- 点击便签按钮或双击画布空白处添加文字；直接编辑标题和正文。
- 拖动卡片顶部移动位置，拖动选中卡片右下角调整大小。
- 上传或拖入本地图片/视频，也可以点击文件夹按钮导入已有生成素材。单文件最大 100 MB。
- 支持 PNG、JPG、WebP、GIF、MP4、WebM、MOV；视频能否播放还取决于浏览器对文件编码的支持，优先使用 H.264 MP4 或 WebM。
- 点击卡片旁的加号或选中工具条中的连线按钮，再点击另一张卡片，建立有方向的连线。
- 选择卡片可换背景色、复制或删除；点击连线后可删除连线。删除卡片同时移除关联连线。
- 拖动空白处、使用平移工具或按住空格拖动，可平移画布；滚轮围绕指针缩放。底部提供缩放、100% 和适应全部内容按钮。
- 支持撤销/重做。视口平移和缩放不进入编辑撤销历史，最多保留 60 个编辑历史快照，刷新后清空编辑历史。
- 修改后约 700 ms 自动保存，拖拽期间延后保存；右上角展示实际保存状态，也可以手动保存。

快捷键：V 选择、H 平移、空格临时平移、Delete/Backspace 删除选中项、Ctrl/⌘ Z 撤销、Ctrl/⌘ Shift Z 重做、Ctrl/⌘ S 保存、0 适应全部内容、Esc 取消连线/选择或关闭素材库。输入框聚焦时保留正常文本编辑快捷键。卡片可通过 Tab 聚焦、Enter 选中。

## 保存和数据边界

当前提供一张本地共享画布，最多 500 张卡片和 1000 条连线，缩放范围为 10%—300%。视图没有固定纸张边界；坐标有防止无效数值的工程范围限制。

画布布局保存在 `backend/code/canvas/board.json`，素材保存在 `backend/code/canvas/assets/`。上传素材和从生成结果导入的素材均使用独立文件，后续清理原项目或临时缓存不会删除这些副本。

布局 JSON 导出包含卡片、连线、视口和本机媒体引用，不是媒体打包，也不包含当前内存中的撤销历史。迁移到其他电脑时应复制完整 `code/canvas/` 目录；本版未提供布局 JSON 导入入口。删除卡片保留素材文件，以便撤销；因此删除卡片不立即回收磁盘空间。

如果后端离线或保存失败，保留页面中的修改并提示错误；离开页面会提示未保存状态。请在关闭页面前重试保存或导出布局。多个窗口采用 revision 冲突检测；冲突时先导出未保存草稿，再重新加载。该机制按当前单后端进程运行方式实现，不是多人实时协作。

## 技术实现

前端：`frontend/app/canvas/page.tsx`、`canvas.css`。通过 DOM 卡片、坐标变换和 SVG 连线实现，不新增第三方前端依赖。侧边栏入口位于 `components/AppShell.tsx`，请求由 Next.js rewrite 到后端。

后端：`backend/api/routers/canvas.py`。Pydantic 校验卡片、视口、连线和容量限制，JSON 使用临时文件与原子替换保存，并对保存版本进行检查。

| API | 行为 |
| --- | --- |
| GET /api/canvas | 返回布局及 revision；首次返回空画布 |
| PUT /api/canvas | 保存布局；revision 不一致返回 409，校验失败返回 422 |
| POST /api/canvas/upload | multipart `file`；验证格式、大小和图片内容 |
| GET /api/canvas/library | 返回结果目录最近 200 个受支持媒体 |
| POST /api/canvas/import | `{ "path": "相对结果目录的路径" }`；复制素材到画布目录 |

只允许画布资产路径进入媒体卡片，生成素材导入校验路径边界。素材上传不进入通用临时缓存目录。当前沿用应用本地单用户访问模式。

## 验证

后端回归：在 backend 目录执行 `.venv/bin/python -m unittest discover -s tests -p 'test_canvas.py' -v`，覆盖保存恢复、冲突、连线完整性、上传限制、独立副本、非法路径和损坏数据保护。

前端生产构建执行 `npm run build`，同时检查 TypeScript。构建配置显式指定当前前端目录为 Turbopack 根目录，以避免上层锁文件导致中文路径标识生成错误。

本版不在画布内直接调用 AI 模型；已有工作台生成的图片和视频可通过素材库导入。画布连线用于创意和镜头关系整理，不触发原六阶段任务。
